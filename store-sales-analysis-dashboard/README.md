# Store Sales Dashboard | Power BI

## Project Overview

An interactive Power BI dashboard for analyzing grocery store sales
performance across stores, product families, locations, time periods,
holidays, and promotions. It helps users explore sales patterns and
compare business performance through interactive visuals and filters.

## Dashboard Preview

![Store Sales Dashboard](dashboard_preview.jpg)

## Key Performance Indicators (KPIs)

-   **Total Sales:** 1bn
-   **Total Transactions:** 5bn
-   **Average Daily Sales:** 357.78
-   **Total Stores:** 54
-   **Sales on Promotion:** 0.65


## Dashboard Highlights

-   **Holiday Analysis:** Compares sales on holidays and non-holidays.
-   **Oil Price Analysis:** Shows sales across low, medium, and high
    oil-price ranges.
-   **Yearly Sales Trend:** Tracks total sales from 2013 to 2017.
-   **Store Type Analysis:** Compares sales across store types A, B, C,
    D, and E.
-   **Day-wise Analysis:** Compares sales across days of the week.
-   **Promotion Analysis:** Compares sales across promotion levels.
-   **State-wise Analysis:** Shows sales distribution across states.

## Interactive Filters

Filter the dashboard by: - Holiday status - Quarter - Product family -
Year - City - Store number

The **Reset** control clears selections and returns the report to its
default view.

## Tools Used

-   Microsoft Power BI Desktop
-   Power Query
-   DAX

## Dataset

Grocery Sales Forecasting dataset (Kaggle).

## How to Use

1.  Clone or download this repository.
2.  Open the `.pbix` file in **Power BI Desktop**.
3.  Refresh the data if the source files are available and Power BI
    requests them.
4.  Use the slicers and visuals to explore sales performance.
