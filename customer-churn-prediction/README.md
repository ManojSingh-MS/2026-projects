# Customer Churn Prediction

## Project Overview
Predict whether a customer is likely to churn using Machine Learning.

## Dataset
- ecommerce_customer_churn_cleaned.csv

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML/CSS

## Machine Learning Model
- Gradient Boosting Classifier

## Features
- Customer information
- Login frequency
- Session duration
- Purchase history
- Engagement metrics

## Model Performance
- Accuracy : 0.923
- Precision: 0.9241
- Recall   : 0.794
- F1 Score : 0.8541
- ROC-AUC  : 0.927

## Deployment
Flask + Render
