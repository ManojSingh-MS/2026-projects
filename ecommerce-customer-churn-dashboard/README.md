# E-Commerce Customer Churn Analytics Dashboard

An interactive Power BI dashboard designed to analyze customer churn and understand customer behaviour and segmentation.

## Dashboard Overview

The dashboard provides an executive summary of customer activity:

- **Total Customers:** 49.94K
- **Churned Customers:** 14.44K
- **Active Customers:** 35.50K
- **Churn Rate:** 28.9%

## Key Visualizations

- Active vs Churned Customers
- Churned Customers by Tenure Group
- Churned Customers by Age Group
- Churned Customers by Login Frequency
- Churned Customer Distribution by LTV Group

## Interactive Filters

- Tenure Group
- Age Group
- Country
- Gender

A Reset button clears the applied filters and restores the default dashboard view.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX

## Project Objective

To identify customer segments with higher churn, understand customer behaviour patterns, and support data-driven customer retention strategies.
